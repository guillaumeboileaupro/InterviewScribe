# UI/UX design

Read `docs/UI_UX.md`. Build a restrained, premium editorial interface where the transcript and recording state dominate. Meet WCAG AA, provide keyboard focus, use 44 by 44 pixel touch targets, support light and dark themes, and avoid gradients, glass effects, excessive rounding, oversized headings and decorative animation.
